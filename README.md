# Yun Huang Portfolio Website

This is my personal portfolio website showcasing my work in AI, HCI, UX, data analysis, web development, and research.

The site is based on an open-source portfolio template and customized with my own content, projects, styling, and deployment setup.

## Featured Projects

- WatchDNA Shopify Translation System
- Agent-Based Simulation of Dissent and Self-Censorship
- Hierarchical Reinforcement Learning for Traffic Signal Control
- HCI / UX Website Redesign
- Data Visualization Dashboard

## Tech Stack

- React
- TypeScript
- Three.js
- GSAP
- WebGL

## Getting Started

```bash
npm install
npm run dev
```
